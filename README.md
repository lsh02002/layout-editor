# 새 쇼핑몰 솔루션 프로젝트 URL (seho-shopping)

- https://seho-shopping.vercel.app/
- 그동안 비공개에서 개선한 웹 빌더 기능들을 layout-editor에도 최대한 반영하겠습니다.
- seho-shopping 은 메인 페이지, 상품 상세 페이지, 로그인 페이지, 회원가입 페이지 그리고 마이페이지를 이 웹 빌더로
  각각 커스터마이징할 수 있고 상품, 주문, 결제, 배송 그리고 회원도 연동되는 쇼핑몰로, 쇼핑몰 수도 이론상 무한대로 
  만들 수 있는 웹 쇼핑몰 솔루션입니다.
- 물론 혼자서 만들기는 불가능하지만 CHATGPT의 도움을 받았고요
- 무엇보다 중요한건 코드를 갔다가 쓰는게 아니라 몇 만줄되는 규모의 코드를 통제(감당)할 수 있는것이라고 합니다.
